# TareaMVVM – "Mis tareas"

App de lista de pendientes para iPhone hecha con SwiftUI y arquitectura MVVM.

- **Model:** `TareaMVVM/Model/Tarea.swift`
- **ViewModel:** `TareaMVVM/ViewModel/TareasViewModel.swift`
- **View:** `TareaMVVM/View/ContentView.swift`

Requisitos: Xcode 13.2 o superior, iOS 15.2+.
Abrir `TareaMVVM.xcodeproj`, elegir un simulador de iPhone y pulsar ▶︎ (Cmd + R).
